# 倉庫管理アプリ

PySide6 で実装した、オフライン運用前提の在庫・パレット管理用デスクトップアプリです。  
真上ビューを中心に、パレットの配置、積み重ね、在庫一覧、出庫履歴を管理できます。

## 主な機能

- 真上ビューによるパレット配置管理
- パレット積み重ね管理
- 在庫一覧表示
- 出庫履歴管理
- タブレットPC対応UI
- 複数パレットの位置強調表示
- 地図上へ配置できるメモオブジェクト
- 同一アイテム自動集約表示
- Export / Import によるデータ共有

## 真上ビュー

- 倉庫マップは `16 × 20`
- 座標は `A〜P`、`1〜20`
- パレットをドラッグして移動可能
- タブレットではスワイプ操作で移動可能
- 2本指ピンチで拡大縮小可能
- 既存パレット近くへドロップすると積み重ねしやすいよう補正
- 同じ場所にあるパレットは段管理される
- blocked location は配置不可
- パレットのない場所をタップ / クリックすると選択解除
- パレットを右クリックすると、編集・向き変更・段操作・列解除・積み替え・出庫のメニューを表示
- メモオブジェクトも真上ビューでドラッグ移動可能
- メモを右クリックすると撤去メニューを表示

## 45度ビュー

- 配置確認用の立体表示
- 視点90°ボタンで90度ずつ回転
- ドラッグで表示位置を移動
- 2本指ピンチで拡大縮小
- blocked location を表示
- パレット移動そのものは真上ビューで実施

## パレット積み重ね

- `1ロケーション = 1スタック列`
- 既存パレット近くへドロップすると自動で同じ列に乗りやすくなる
- 段順は `stack_order` で管理
- 保管場所表示は `A20-1` のように表示
- 同じロケーション内では `A20-1`, `A20-2`, `A20-3` のように段表示される
- 列解除は、選択中のパレット1枚だけを仮置きエリアへ戻す

## 仮置きエリア（未配置）

- 新規登録直後のパレット
- メモ追加直後のメモ
- 出庫履歴から復元したパレット
- 列解除したパレット
- 積み替えで作成した空パレット

上記は仮置きエリア（未配置）へ入ります。

- 上限は `10個`
- 上限を超える操作は警告して中止
- 仮置き中のパレットは、上部集計から除外
  - パレット数
  - 明細数
  - 総枚数
  - 面積使用率

## メモオブジェクト

- `メモ追加` から地図上の注釈を登録可能
- 本文は複数行入力可能
- 本文の最初の空でない行を地図上ラベル・詳細表示タイトルとして使用
- サイズは `L` / `LL` / `EL` / `OL`
- 登録直後は仮置きエリア（未配置）へ配置
- 真上ビューで通常パレットと同じようにドラッグ移動可能
- 通常パレットと重ねて表示できるよう、透明ベースと斜線表示で描画
- 選択すると詳細ポップアップにサイズと本文全文を表示
- メモ選択中は `明細編集` ボタンがメモ編集として動作
- ダブルクリックでもメモ編集可能
- 右クリックの `撤去` で削除
- メモは在庫ではないため、次の対象には含めない
  - パレット数
  - 明細数
  - 総枚数
  - 高さ計算
  - 面積使用率
  - 出庫履歴

## 在庫一覧

- 閲覧・コピー専用
- セル直接編集不可
- 列幅変更可能
- タブレット向けにヘッダー境界のタッチ判定を拡大
- 罫線を強化して境界を見やすく調整
- 列ヘッダーをクリックすると並び替え
- ダブルクリックすると真上ビューで該当パレット位置を強調表示
- 同一アイテムが複数場所にある場合は、全パレット位置を同時強調表示

### 表示列

- パレット番号
- 品番
- サイズ
- 厚み
- 加工 / 裏表
- グレード
- 総枚数
- 保管場所
- 入庫日

### 保管場所表示例

- `A20-1`
- `B12-3`

### 集約ルール

同一アイテムは次のキーで自動集約表示します。

- 品番
- サイズ
- 厚み
- 加工 / 裏表
- グレード
- 備考

複数パレットに分かれている場合:

- 総枚数は合計
- 保管場所はカンマ区切り
- パレット番号はカンマ区切り
- 入庫日もカンマ区切り

## 出庫一覧

- 出庫済みパレットの履歴を表示
- 右クリックで復元 / 履歴削除
- 複数選択対応
- 列幅変更可能
- 在庫一覧と同様に罫線表示を強化

## 入力ルール

新規登録とパレット編集は同じルールです。  
半角入力が基本ですが、対象欄では全角入力でも自動で正規化されます。

### 品番・パレット番号

- 全角英数字は半角へ自動変換
- 英字は大文字化
- 空白は除去
- 日本語不可

例:

- `３９` → `39`
- `ｐ００１` → `P001`

NG:

- `テスト`
- `品番39`

### 加工 / 裏表

- 日本語OK
- 英数字は半角大文字化
- `￥` `\` `。` `？` `?` は `/` に変換

例:

- `ｓ／ｓ` → `S/S`
- `Ｃ￥Ｃ` → `C/C`
- `Ｓ。Ｓ` → `S/S`
- `Ｃ？Ｃ` → `C/C`
- `エンボスｓ／ｓ` → `エンボスS/S`

### 厚み(mm)

- 全角数字は半角へ変換
- `、` `・` `･` `．` `，` `,` は小数点として扱う
- `3-3.5` や `3~3.5` の範囲表記OK
- 表示値・保存値は範囲表記のまま保持
- 高さ計算は文字列内の最大値を使用

例:

- `５、５` → `5.5`
- `３－３．５` → `3-3.5`
- `３～３．５` → `3~3.5`

NG:

- `約3.5`
- `3mm`
- `あいうえお`

### 枚数

- 全角数字は半角へ変換
- 数字のみ許可
- 範囲は `1〜600`

例:

- `８０` → `80`

NG:

- `80枚`
- `abc`
- `あいうえお`

### 備考

- 日本語OK
- 20文字以内
- 改行不可

## 新規登録

- 初期値
  - 品番 `39`
  - サイズ `LL`
  - 厚み `10`
  - 加工 / 裏表 `S/S`
  - グレード `A`
  - 枚数 `80`
- 新規登録時のロケーション入力はなし
- 登録後は仮置きエリア（未配置）へ配置
- 明細追加後も同じ内容を続けて編集可能
- 追加済み明細を選択すると、内容を再編集可能

## パレット編集

- パレット番号変更可能
- 入庫日変更可能
- 色設定変更可能
- 向き変更可能
- 明細の追加 / 削除 / 並び替え可能
- 明細行選択時は選択色で強調表示
- ダブルクリックやボタンから編集導線あり
- Enter キーでは最終 OK 確定しない

## 積み替え

- パレットAの一部枚数をパレットBへ移動可能
- 同じ明細でも自動合算しない
- 空パレットを作って積み替え可能
- 空パレット作成時は仮置きエリアへ配置

## 面積使用率

- `16 × 20` の使用可能セル数を基準に計算
- `blocked location` を除外して算出
- 同じロケーションに積み重なっている場合は `1セル` として扱う
- 仮置きエリア（未配置）は除外

## blocked location

- 置けないマス設定で指定
- 既にパレットがあるマスは設定不可
- 真上ビュー / 45度ビューの両方で表示
- 面積使用率の母数から除外

## タブレットPC向け仕様

- ソフトウェアキーボード対応
- 厚み / 枚数も通常の入力欄として扱い、キーボード表示を優先
- 列幅変更のタッチ判定を拡大
- 在庫一覧 / 出庫一覧の罫線強化
- Enterキー誤登録防止
- 最終 OK は Enter で確定しない
- 列幅変更はヘッダー境界付近をドラッグ
- 真上ビュー / 45度ビューとも 2本指ピンチで拡大縮小

## 厚み・枚数の上下ボタン

- クリックで1回増減
- 長押しで連続増減
- 厚みの範囲は `0.3〜35.0`
- 枚数の範囲は `1〜600`
- 厚みが範囲表記の場合でも、矢印操作時は最大値基準の単一値へ切り替えて増減

## 自動色判別

自動色は明細内容から決定します。

- `C/C` のみ: 紫
- `#38`: 赤
- `#39`: 青
- `#45`: 緑
- `#50`: 桃
- `#40`: 黄
- 混在 / その他: グレー

新規登録・パレット編集では:

- 自動判別
- 手動指定

を切り替え可能です。

## 保存・読込

- 保存タイミングは、変更確定時のみ
  - 編集確定時
  - ダイアログOK時
  - 移動完了時
  - 積み替え確定時
  - 出庫確定時
  - 新規登録確定時
  - メモ追加・メモ編集・メモ撤去確定時
- 保存失敗時はアラート表示
  - 再試行
  - 別名保存
- 日次バックアップを `backups/` に自動保存
  - 例: `backups/inventory-data-2026-05-11.json`
  - 同じ日は1回だけ作成
  - 既存ファイルの「その日最初に保存する前の状態」を残す
  - 90日より古い日次バックアップは自動削除
  - バックアップ作成に失敗しても通常保存は継続し、`store-error.log` に記録
- Export / Import でデータ共有
- Import 時は上書き確認あり
- 本体とバックアップの両方が破損している場合は起動停止

## 注意事項

- 在庫一覧は直接編集できません
- 明細変更は `パレット編集` から行ってください
- 厚み範囲表記は表示値として保持されます
- 高さ計算のみ最大値を使用します
- 加工 / 裏表 と 備考 以外は、日本語入力すると保存時エラーになります
