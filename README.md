# Warehouse App

PySide6 で実装した、パレット単位の在庫管理デスクトップアプリです。  
通常はローカル保存で運用し、共有が必要な時だけ `Export / Import` で JSON を受け渡します。

## 主な機能

- 真上マップでパレット位置を管理
- パレットをドラッグ / スワイプ感覚で移動
- 同じ場所で積み重ね管理
- 45度ビューで位置と高さ感を確認
- 1パレットに複数アイテムを登録
- 在庫一覧の表示と列ヘッダー並び替え
- 出庫処理、出庫履歴、履歴からの復元
- Excel 貼り付け用の一覧コピー
- JSON の `Export / Import`

## データ構造

- 在庫は `パレット単位` で管理
- 1パレットに複数明細を載せられる
- 明細は次の項目を持つ

- `品番`
- `サイズ`
- `厚み`
- `加工 / 裏表`
- `グレード`
- `枚数`
- `備考`

例:

`#38-LL10 S/S A 80`

## パレットサイズ

- `L = 1400 x 1300mm`
- `LL / EL = 2300 x 1300mm`
- `OL = 3500 x 1400mm`

## 画面

### 真上

- 倉庫内の位置を平面で表示
- パレットをドラッグして移動
- 積み列を選ぶと少し展開して見やすく表示
- パレット選択時は詳細カードを固定表示
- 詳細カードはドラッグ移動可能
- 詳細カードをダブルクリックすると編集を開く

### 45度ビュー

- 入口基準の立体表示
- `入口` は常時表示
- `視点90°` ボタンで 90 度刻み回転
- 空き領域ドラッグでパン移動
- ホイールで拡大 / 縮小

### 在庫一覧

- 全在庫を一覧表示
- 列ヘッダークリックで昇順 / 降順切り替え
- `一覧コピー` で Excel へ貼り付け可能
- 検索欄はこのタブでのみ表示

### 出庫一覧

- 出庫したパレットの履歴を表示
- `復元` で在庫へ戻す
- `履歴削除` で履歴削除
- 復元時は入口へ戻す

## 新規登録

- `新規登録` ボタンから登録
- 新規登録したパレットは入口に配置
- ロケーション入力は不要
- 明細の初期値:

`39 / LL / 10 / S/S / A / 80`

- `明細を追加` で現在の入力内容を明細へ追加
- 追加後も入力値は残る
- 厚みは自由入力可能
- 厚み欄は上下キー / 右側ボタンで 1 ずつ増減可能

## パレット編集

- パレット番号変更可能
- 明細の追加 / 削除 / 並び替え可能
- アイテム順は `1 = 一番上`
- 厚みは文字列で保持

## 厚み入力

厚みは固定整数ではなく自由入力です。

入力例:

- `6.5`
- `3-3.5`
- `3~3.5`

高さ計算ルール:

- 単独値はその値を使用
- 範囲表記は最大値を使用

例:

- `3-3.5` → `3.5mm` として計算

## 色設定

### 固定色

色選択では見本付きで固定色を選べます。  
現在は `AUTO` 以外に約 16 色の固定色があります。

### 自動色

`自動` は新規登録時のみ選択可能です。  
登録時点で具体色へ確定し、その後は固定色として扱います。編集画面では `自動` は出しません。

自動色ルール:

- `C/C` が1件でもある: 紫
- 品番 `#38`: 赤
- 品番 `#39`: 青
- 品番 `#45`: 緑
- 品番 `#50`: 桃
- 品番 `#40`: 黄
- 品番混在: その他
- それ以外: その他

`その他` はグレー系 `#7A8EA6` です。

## 積み替え

- あるパレットの一部枚数を別パレットへ移動
- 移動先へ同じ明細をコピーし、枚数だけ分ける
- 自動マージはしない

## 出庫

- 選択中パレットを `出庫` で倉庫表示から外す
- 出庫内容は `出庫一覧` に履歴として残る
- 履歴から復元可能

## パレット番号重複

重複時は自動で末尾に連番を付けます。

例:

- `R080324`
- `R080324-1`
- `R080324-2`

対象:

- 新規登録
- パレット編集
- 出庫履歴からの復元

## 保存ファイル

- 通常保存: `inventory-data.json`
- エクスポート: 任意の JSON

`exe` 化した場合も、基本は `exe` と同じフォルダの `inventory-data.json` を使用します。

## 起動方法

### Python 実行

1. Python 3.11 以上を用意
2. `python -m pip install -r requirements.txt`
3. `run_pyside.bat` を実行

### EXE ビルド

- `WarehouseApp.spec` または `warehouse_app.spec` を使用
- アイコンは `icon.ico` を埋め込み

## 主なファイル

- `warehouse_app.py`
  アプリ本体
- `requirements.txt`
  Python 依存関係
- `run_pyside.bat`
  Python 実行用
- `WarehouseApp.spec`
  EXE ビルド設定
- `warehouse_app.spec`
  EXE ビルド設定
- `inventory-data.json`
  ローカル保存データ
