# Warehouse App

PySide6 で作成した、パレット単位の在庫管理デスクトップアプリです。  
オフライン運用を前提にしていて、通常はローカル保存、共有が必要な時だけ `Export / Import` でデータ受け渡しできます。

## 主な機能

- 真上マップでパレット位置を確認
- パレットをドラッグ / スワイプ感覚で移動
- 同じ場所で積み重ね管理
- 左下45度ビューで立体っぽく確認
- 1パレットに複数アイテムを登録
- パレットごとの入庫日管理
- アイテムごとの備考入力
- 在庫一覧の表示、列ヘッダークリックで並び替え
- 出庫処理、出庫一覧で履歴確認
- 出庫履歴から復元
- Excel 貼り付け用の一覧コピー
- JSON の `Export / Import`

## データの考え方

- 在庫は `パレット単位` で管理します
- 1つのパレットに複数種類のアイテムを載せられます
- アイテムは `品番 / サイズ / 厚み / 加工・裏表 / グレード / 枚数 / 備考` を持ちます
- 例: `#38-LL10 S/S A 80`

サイズの目安は次です。

- `L = 1400 x 1300mm`
- `LL / EL = 2300 x 1300mm`
- `OL = 3500 x 1400mm`

## 画面の使い方

### 真上

- 倉庫内の位置を平面で見ます
- パレットをドラッグして移動できます
- 重なっている列を選ぶと、少し展開して見やすくなります
- パレットをクリックすると、明細カードが固定表示されます
- 明細カードはドラッグで移動できます
- 明細カードをダブルクリックすると編集を開けます

### 左下45°

- パレットの高さ感や積み重なりを立体風に確認します
- パレット選択や明細確認ができます

### 在庫一覧

- 全在庫を一覧表示します
- 検索窓はこのタブでのみ表示されます
- 列ヘッダーをクリックすると、その項目で昇順 / 降順の並び替えができます
- `一覧コピー` で Excel に貼り付けできます

### 出庫一覧

- 出庫したパレットの履歴を確認できます
- `復元` で在庫へ戻せます
- `履歴削除` で不要な履歴を消せます
- 復元時は新規登録と同じく `入口` に置かれます
- パレット番号が重複している場合は `-1`, `-2` を自動付与します

## 新規登録

- `新規登録` ボタンから入力します
- 新規登録したパレットは `入口` に置かれます
- ロケーション入力は不要です
- 明細の初期値は次です

`39 / LL / 10 / S/S / A / 80`

- `明細を追加` を押すと、その時の入力内容で明細が追加されます
- 追加後も入力内容は残るので、連続入力しやすくしています

## 編集

- 選択したパレットの `明細編集` ができます
- パレット番号も変更できます
- アイテムの追加 / 削除 / 並び替えができます
- アイテムの並びは `1 = 一番上積み` です

## 積み替え

- `積み替え` で、あるパレットの一部枚数を別パレットへ移せます
- 移動先へ同じ明細を自動コピーし、枚数だけ分けます
- 自動マージはしません

## 出庫

- パレット選択後に `出庫` ボタンで倉庫表示から外せます
- 出庫した内容は `出庫一覧` に履歴として残ります

## 保存ファイル

- 通常保存: `inventory-data.json`
- エクスポート: 任意の JSON ファイル

`exe` 化した場合も、基本的に `exe` と同じフォルダの `inventory-data.json` を使います。

## 起動方法

### Python で起動

1. Python 3.11 以上を用意
2. `python -m pip install -r requirements.txt`
3. `run_pyside.bat` を実行

### EXE を作る場合

- `WarehouseApp.spec` または `warehouse_app.spec` を使ってビルド
- アイコンは `icon.ico` を使用

## 主なファイル

- `warehouse_app.py`
  アプリ本体
- `requirements.txt`
  Python 依存関係
- `run_pyside.bat`
  Python 実行用
- `WarehouseApp.spec`
  EXE ビルド設定
- `inventory-data.json`
  ローカル保存データ
