# 倉庫管理アプリ

PySide6 で実装した、オフライン運用前提のパレット在庫・倉庫レイアウト管理アプリです。

真上ビューによる倉庫マップ管理を中心に、

* 在庫管理
* パレット配置管理
* 段積み管理
* 出庫履歴管理
* 棚卸補助
* 空パレット管理
* スライス余り管理
* 明細不明品管理

を行えます。

# 通常の運用フロー

1. 新規登録
2. 仮置きエリアへ追加
3. 真上ビューへ配置
4. 必要に応じて段積み
5. 在庫一覧で確認
6. 出庫
7. 出庫履歴へ保存

---

# 真上ビュー

* 倉庫マップは 12列 × 23段
* 列は A～L
* 段は 1～23
* パレットをドラッグして移動可能
* メモもドラッグ移動可能
* パレットのない場所をクリックすると選択解除
* ドラッグ中は候補座標を表示
* 同じ場所へ配置すると段積みになる
* Undo / Redo 対応

### 通路列

以下の列は通路扱いです。

* B
* E
* F
* J

表示上は

* B(通路)
* E(通路)
* F(通路)
* J(通路)

と表示されます。

通路にも配置は可能ですが、本来は置かない運用を想定しています。

---

# 45度ビュー

* 配置確認用の立体表示
* 視点90°回転可能
* ドラッグで表示移動
* ピンチ操作で拡大縮小
* 段積み状態の確認向け
* パレット移動は真上ビューで行う

---

# パレット積み重ね

* 1ロケーション = 1スタック列
* 同じマスに配置すると段積み
* 保管場所は A23-1 のように表示
* 段数が増えるほど右上へ少しずらして表示
* 列解除で1枚だけ未配置へ戻せる

---

# 仮置きエリア（未配置）

以下は未配置エリアへ入ります。

* 新規登録直後のパレット
* メモ追加直後のメモ
* 出庫履歴から復元したパレット
* 列解除したパレット
* 積み替えで作成した空パレット

上限:

* 10個

未配置中は使用率や集計対象に含まれません。

---

# メモ

「メモ追加」から登録します。

用途例:

* 空パレット
* スライス余り
* 明細不明
* 一時置き
* 注意事項

特徴:

* 複数行入力対応
* 1行目をタイトル表示
* サイズ L / LL / EL / OL
* 通常パレットと重ねて配置可能
* 透明＋斜線表示
* ダブルクリック編集可能
* 右クリックの撤去で削除

メモは在庫ではないため以下に含まれません。

* 在庫集計
* 高さ計算
* 使用率
* 出庫履歴

---

# 在庫一覧

現在の在庫を一覧表示します。

機能:

* 検索
* 並び替え
* 複数選択
* 列幅変更
* 位置強調表示

ダブルクリックすると該当パレット位置を真上ビューで強調表示します。

## 一覧コピー

在庫一覧の表示内容をそのままクリップボードへコピーします。

用途:

* Excel貼り付け
* 内容確認
* 一時共有

## 棚卸データ出力

棚卸表向けの集計データをクリップボードへコピーします。

特徴:

* 同一アイテムは数量合算
* 棚卸表へ貼り付ける用途

一覧コピーとは用途が異なります。

---

# 出庫一覧

出庫済み履歴を表示します。

機能:

* 検索
* 並び替え
* 複数選択
* 復元
* 削除

出庫日は先頭列に表示されます。

復元したパレットは未配置エリアへ戻ります。

---

# 新規登録

登録後は未配置エリアへ配置されます。

標準初期値:

* 品番 39
* サイズ LL
* 厚み 10
* 加工 S/S
* グレード A
* 枚数 80

アプリ起動中は直前登録した明細を次回登録時の初期値として利用します。

アプリ再起動後は標準値へ戻ります。

---

# パレット編集

編集可能項目:

* パレット番号
* 入庫日
* 色設定
* 向き
* 明細追加
* 明細削除
* 明細並び替え

ダブルクリックでも編集可能です。

---

# 積み替え

* 一部枚数を別パレットへ移動可能
* 空パレットを作成して移動可能
* 自動合算はしない

---

# 使用率

使用率は通路列を除いた通常置場を基準に計算します。

通常置場:

* 184マス

使用率に含む:

* パレットが置かれているマス
* 置けないマス

特徴:

* 段積みは1マス扱い
* 未配置は除外
* 通路列は分母に含まない
* 通路列へ配置すると100%を超える

例:

* 通路以外184マス使用 → 100%
* 通路にも配置 → 100%超

---

# 置けないマス

設備や作業スペースなど配置できない場所を登録します。

特徴:

* 真上ビュー表示
* 45度ビュー表示
* 使用率では使用済み扱い
* 通路列とは別管理

---

# 色説明設定

## 固定説明色

* 赤 [#38]
* 青 [#39]
* 黄 [#40]
* 緑 [#45]
* 桃 [#50]
* 紫 [C/C]
* その他 [混在 / その他]

変更不可です。

## 編集可能色

* 紺 [空パレット]
* 橙 [スライス余り]
* 青緑 [明細不明]
* その他の色

説明は変更できます。

---

# 自動色判別

* C/C → 紫
* #38 → 赤
* #39 → 青
* #40 → 黄
* #45 → 緑
* #50 → 桃
* その他 → グレー

---

# Export / Import

通常運用では基本的に使用しません。

用途:

* バックアップ
* PC移行
* データ共有
* 復旧

Importは現在データを書き換えるため注意してください。

---

# 保存とバックアップ

保存タイミング:

* 新規登録
* 編集
* 出庫
* 積み替え
* 移動確定
* メモ追加
* メモ編集
* メモ撤去

ドラッグ中は保存しません。

## 自動バックアップ

backups フォルダへ日次バックアップを保存します。

例:

backups/inventory-data-2026-06-10.json

特徴:

* その日の最初の保存時のみ作成
* 同日は追加作成しない
* 90日超は自動削除
* バックアップ失敗時も通常保存は継続

# タブレット対応

* ソフトウェアキーボード対応
* スワイプスクロール
* 長押し＋スワイプで複数選択
* ピンチズーム
* タッチ操作向けUI調整

---

# 注意事項

* 在庫一覧は直接編集不可
* 編集はパレット編集から行う
* メモは在庫ではない
* 通路への配置は可能だが非推奨
* Importは上書きに注意
* 本体データとバックアップの両方が破損した場合は起動停止する
