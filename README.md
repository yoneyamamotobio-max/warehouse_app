# Warehouse App

PySide6 で作成した、パレット単位の在庫管理デスクトップアプリです。  
オフライン運用を前提にしており、通常はローカル保存、共有時のみ `Export / Import` を使う構成です。

## 主な機能

- 真上マップでパレット位置をドラッグ移動
- 45度ビューで積み高さと位置関係を確認
- 1パレットに複数アイテムを登録
- 積み替え、出庫、出庫履歴からの復元
- 在庫一覧 / 出庫一覧の表示
- Excel に貼り付けやすい形式で一覧コピー、棚卸データ出力
- JSON の `Export / Import`

## 位置とマップ

- グリッドは `20 x 20`
- 横軸はアルファベット、縦軸は数字
- 新規登録したパレットは仮置きエリア（未配置）に配置されます
- 仮置きエリア（未配置）の上限は10個です
- 仮置きエリア（未配置）のパレットは、パレット数・明細数・総枚数・面積使用率にカウントしません
- 面積使用率は、同じロケーションに積み重なっているパレットを1列分としてカウントします
- 位置は入力欄ではなく、真上マップ上のドラッグで決めます
- 復元したパレットも元位置ではなく仮置きエリア（未配置）に戻ります

## パレットサイズ

- `L = 1400 x 1300mm`
- `LL / EL = 2300 x 1300mm`
- `OL = 3500 x 1400mm`

## 明細フォーマット

1パレットに複数明細を持てます。  
表示例:

`#39-LL10 S/S A 80`

入力項目:

- 品番
- サイズ
- 厚み(mm)
- 加工 / 裏表
- グレード
- 枚数
- 備考

## 入力ルール

### 入庫日

- `YYYY-MM-DD` 形式のみ
- 新規登録時は当日の日付を初期表示

### 品番

- スペースは自動除去
- 全角数字 / 英字は半角へ補正
- 文字数の固定制限なし

### サイズ

- 選択肢のみ
- `L / LL / EL / OL`

### 厚み

- 半角数字と小数点で入力
- `0.3mm 以上 35mm 以下`
- `0` や負数は不可
- `6.5` のような小数入力可
- `3-3.5` や `3~3.5` のような範囲表記も可
- 範囲表記は最大値で高さ計算
  - 例: `3-3.5` は `3.5mm` として計算

### グレード

- 選択肢のみ
- `A / B / C / K / 片A / S`

### 枚数

- `1 ～ 600`
- `0`、負数、小数は不可
- `0` のまま追加しようとした場合は警告を表示

### 備考

- 改行不可
- 20文字以内

## 色設定

パレット色は `自動判別` と `手動指定` を切り替えられます。  
新規登録画面、パレット編集画面の両方で設定できます。

### 手動指定

固定色から選択します。  
入力画面ではプレビュー色が表示されます。

### 自動判別

自動判別は、パレット内の明細内容から色を決めます。  
優先順は次の通りです。

1. 加工 / 裏表に `C/C` が1件でも含まれる場合: `紫`
2. 品番が単一で `38` のみ: `赤`
3. 品番が単一で `39` のみ: `青`
4. 品番が単一で `45` のみ: `緑`
5. 品番が単一で `50` のみ: `桃`
6. 品番が単一で `40` のみ: `黄`
7. 品番混在: `その他`
8. 上記以外の品番: `その他`

### 自動判別の全パターン

- `C/C` を含む: 紫
- `#38` のみ: 赤
- `#39` のみ: 青
- `#45` のみ: 緑
- `#50` のみ: 桃
- `#40` のみ: 黄
- 品番混在: その他
- それ以外の品番: その他

`その他` の色はグレー系 `#7A8EA6` です。

### 色選択肢

- 赤 `[#38]`
- 青 `[#39]`
- 緑 `[#45]`
- 桃 `[#50]`
- 黄 `[#40]`
- 紫 `[C/C]`
- その他 `[混在 / その他]`
- 橙
- 青緑
- 紺
- 黄緑
- 茶
- 白
- 黒
- 水
- 紅

## 積み重ね

- パレットは同じ位置に積み重ね可能
- 積み列は真上マップで少しずらして表示
- 45度ビューでは真上に積み上がる表示
- 段の上下変更が可能
- 積み解除時は仮置きエリア（未配置）へ退避

## 新規登録

- `新規登録` ボタンから登録
- 初期値:
  - 品番 `39`
  - サイズ `LL`
  - 厚み `10`
  - 加工 / 裏表 `S/S`
  - グレード `A`
  - 枚数 `80`
- `明細を追加` 後も入力値は残るため、連続入力しやすい仕様

## パレット編集

- パレット番号変更可
- 入庫日変更可
- 色設定変更可
- アイテムの追加 / 編集 / 削除可
- 明細順は `1 = 一番上`
- 明細行追加は先頭に追加

## 積み替え

- パレットAの一部枚数をパレットBへ移動可能
- 明細はコピーされ、移動先で再入力不要
- 自動で同一明細へ合算はしません
- 積み替え枚数は `1以上`
- 移動元の枚数を超える積み替えは不可
- 移動元明細は `上 → 下` の順で表示
- 備考も表示

## 出庫と復元

### 出庫

- 選択中パレットを `出庫`
- マップと在庫一覧からは非表示
- 出庫一覧へ履歴として保存

### 復元

- 出庫一覧から `復元`
- 元位置ではなく仮置きエリア（未配置）に戻ります
- 復元確認ダイアログの既定値は `Yes`

## 在庫一覧

- 在庫一覧タブで全明細を確認
- 列ヘッダークリックで昇順 / 降順切替
- 検索欄は在庫一覧タブの時だけ表示
- 検索例プレースホルダ: `例: 39 LL 10 A`
- `一覧コピー` で Excel に貼り付け可能
- `棚卸データ出力` で同一アイテムを合算した一覧をクリップボードへ出力

棚卸データの集計キー:

- 品番
- サイズ
- 厚み
- 加工 / 裏表
- グレード

グレード違いは別アイテム扱いです。

## 出庫一覧

- 出庫履歴を一覧表示
- 履歴削除可
- 復元可

## パレット番号重複

パレット番号が重複した場合は、自動で連番を付与します。

例:

- `R080324`
- `R080324-1`
- `R080324-2`

対象:

- 新規登録
- パレット編集
- 出庫履歴からの復元

## 保存

- 通常保存先: `inventory-data.json`
- 保存時は一時ファイル `inventory-data.json.tmp` を作成
- 既存ファイルがあれば `inventory-data.json.bak` を作成
- 読み込み順は `本体 -> .bak -> 空データ`
- 壊れた本体ファイルは `*.corrupt.json` として退避
- 読み込み失敗は `store-error.log` に記録

保存は毎回の画面更新ではなく、データ変更時のみ実行します。

## 主なファイル

- `warehouse_app.py`
  - アプリ本体
- `requirements.txt`
  - Python 依存関係

  - Python 実行用
- `WarehouseApp.spec`
  - EXE ビルド設定
- `warehouse_app.spec`
  - EXE ビルド設定
- `inventory-data.json`
  - ローカル保存データ
- `icon.ico`
  - アプリアイコン

## 起動方法

### Python 実行

1. Python 3.11 以上を用意
2. `python -m pip install -r requirements.txt`
3. `run_pyside.bat` を実行

### EXE ビルド

- `WarehouseApp.spec` または `warehouse_app.spec` を使用
- アイコンは `icon.ico` を参照
