# 大阪工場倉庫アプリ

PySide6 で実装した、パレット単位の在庫管理デスクトップアプリです。  
通常運用はオフライン前提で、共有時のみ `Export / Import` を使う構成です。

## 概要

- 真上ビューでパレット位置をドラッグ移動
- 45度ビューで積み高さと位置関係を確認
- 1パレットに複数明細を登録
- 積み替え、出庫、復元に対応
- 在庫一覧 / 出庫一覧を搭載
- 一覧コピー、棚卸データ出力に対応
- JSON 保存、Export / Import に対応

## マップ仕様

- グリッドは `16 x 20`
- 横軸は `A〜P`
- 縦軸は `1〜20`
- 1ロケーション = 1スタック列
- 同じロケーションに置いたパレットは積み列として扱います
- 真上ビューでは積み列を少しずらして表示します
- 45度ビューでは真上に積み上がる形で表示します

## 仮置きエリア（未配置）

- 新規登録直後のパレット
- 出庫履歴から復元したパレット
- 列解除したパレット
- 積み替えで新しく作った空パレット

上記は仮置きエリア（未配置）へ入ります。

- 上限は `10個`
- 上限に達した場合は、先に倉庫内へ配置してから次の操作を行います
- 仮置き中のパレットは次の集計に含めません
  - パレット数
  - 明細数
  - 総枚数
  - 面積使用率

## 面積使用率

- 面積使用率は `使用中セル数 / 使用可能セル数`
- 使用可能セル数は `16 x 20` から `blocked_locations` を引いた数
- 同じロケーションに積み重なっているパレットは 1セルとしてカウント
- 仮置きエリア（未配置）はカウントしません

## パレットサイズ

- `L = 1400 x 1300mm`
- `LL / EL = 2300 x 1300mm`
- `OL = 3500 x 1400mm`

## 明細フォーマット

1パレットに複数明細を持てます。  
表示例:

`#39-LL10 S/S A 80`

入力項目:

- 品番
- サイズ
- 厚み(mm)
- 加工 / 裏表
- グレード
- 枚数
- 備考

## 入力ルール

新規登録とパレット編集は同じルールです。

### パレット番号

- 半角入力が基本
- 全角英数字は半角寄りに正規化
- 空白は除去
- 既存番号と重複した場合は `-1`, `-2` のように自動連番

### 入庫日

- `YYYY-MM-DD` 形式のみ
- 実在する日付のみ
- 未来日は不可
- 新規登録時は当日を初期表示

### 品番

- 半角英数字のみ
- 全角英数字は半角寄りに正規化
- 大文字化
- 空白除去
- 日本語は不可

例:

- `３９` → `39`
- `ab 12` → `AB12`

### サイズ

- 選択肢のみ
- `L / LL / EL / OL`

### 厚み(mm)

- `0.3 以上 35.0 以下`
- 単一値と範囲表記に対応
  - `3.5`
  - `3-3.5`
  - `3~3.5`
- 全角数字は半角寄りに正規化
- 小数点として次の文字を `.` に変換
  - `、`
  - `・`
  - `･`
  - `．`
  - `，`
  - `,`
- 波ダッシュ系は `~` に正規化
- ハイフン系は `-` に正規化
- 日本語や不要文字は不可

例:

- `５、５` → `5.5`
- `３－３．５` → `3-3.5`
- `３～３．５` → `3~3.5`

高さ計算:

- 保存値は範囲表記のまま保持
- 高さ計算だけ文字列中の最大数値を使います
  - 例: `3-3.5` は `3.5mm` として計算

### 加工 / 裏表

- 日本語入力可
- 英数字と記号は半角寄りに正規化
- 英字は大文字化
- 連続空白は1つに整理
- 前後空白は除去

例:

- `ｓ／ｓ` → `S/S`
- `ｃ／ｃ` → `C/C`
- `エンボス` → `エンボス`
- `エンボス ｓ／ｓ` → `エンボス S/S`

### グレード

- 選択肢のみ
- `A / B / C / K / 片A / S`

### 枚数

- `1〜600`
- 半角数字のみ有効
- 全角数字は半角寄りに正規化
- 日本語、英字、記号は不可

例:

- `８０` → `80`
- `80枚` → エラー

### 備考

- 日本語可
- 改行不可
- 20文字以内

## 色設定

パレット色は `自動判別` と `手動指定` を切り替えられます。

### 自動判別ルール

優先順:

1. 加工 / 裏表がすべて `C/C` の場合は紫
2. 品番が単一で `38` のみなら赤
3. 品番が単一で `39` のみなら青
4. 品番が単一で `45` のみなら緑
5. 品番が単一で `50` のみなら桃
6. 品番が単一で `40` のみなら黄
7. 品番混在またはその他はグレー

### 手動色

次の色から選択できます。

- 赤
- 青
- 緑
- 桃
- 黄
- 紫
- その他
- 橙
- 青緑
- 紺
- 黄緑
- 茶
- 白
- 黒
- 水
- 紅

## 真上ビュー

- パレットをドラッグして位置変更
- タブレットではスワイプで移動
- 2本指ピンチで拡大縮小
- 空白クリックで選択解除
- 置けないマス設定あり
- 入口は下側中央
- 仮置きエリアは、パレットがある時だけ表示

### 右クリックメニュー

真上ビューと45度ビューのパレット右クリックで次を実行できます。

- 明細編集
- 向き変更
- 段を上げる
- 段を下げる
- 列を解除
- 積み替え
- 出庫

## 45度ビュー

- 立体確認用
- パレット移動は不可
- 視点90°ボタンで向きを切替
- ドラッグで表示位置移動
- 2本指ピンチで拡大縮小
- blocked_locations も表示

## 新規登録

- 初期値
  - 品番 `39`
  - サイズ `LL`
  - 厚み `10`
  - 加工 / 裏表 `S/S`
  - グレード `A`
  - 枚数 `80`
- `明細を追加` 後も入力値は残ります
- 追加済み明細を選択すると再編集できます
- 登録直後は仮置きエリア（未配置）に入ります

## パレット編集

- パレット番号変更可
- 入庫日変更可
- 色設定変更可
- 向き変更可
- 明細の追加 / 編集 / 削除可
- 明細順は `1 = 一番上`
- 新規登録と同じ入力ルールで検証

## 積み替え

- パレットAの一部枚数を、既存パレットまたは空パレットへ移動
- 自動で同一明細へ合算しません
- 移動元枚数を超える積み替えは不可
- 空パレットを作る場合は仮置きエリア（未配置）へ作成

## 出庫と復元

### 出庫

- 選択中パレットを倉庫表示から外して出庫一覧へ移動

### 復元

- 出庫一覧から復元可
- 元位置ではなく仮置きエリア（未配置）へ戻します
- 復元確認ダイアログの既定値は `Yes`

## 在庫一覧

在庫一覧は閲覧・コピー専用です。セルの直接編集はできません。

表示列:

- 品番
- サイズ
- 厚み
- 加工 / 裏表
- グレード
- 総枚数
- 保管場所
- パレット番号

補足:

- 保管場所は `A20-1` のように `座標-段数` で表示
- 同じアイテムが複数場所にある場合はカンマ区切りでまとめて表示
- パレット番号も複数ならカンマ区切り
- 列ヘッダークリックで並び替え
- 列幅はヘッダー境界ドラッグで変更可
- タブレット向けに、ヘッダー境界付近のリサイズ判定を広げています
- 行をダブルクリックすると真上ビューへ切り替えて該当パレットを強調表示
  - 1件ならそのパレットを選択
  - 複数件なら該当パレットをまとめて強調表示

### 検索

- スペース区切り AND 検索
- 例: `39 LL 10 A`

### 一覧コピー

- Excel に貼り付けやすいタブ区切りでコピー

### 棚卸データ出力

- 同じアイテムを集計してクリップボードへ出力
- 集計キー
  - 品番
  - サイズ
  - 厚み
  - 加工 / 裏表
  - グレード
- グレード違いは別アイテム扱い

## 出庫一覧

- 出庫履歴を一覧表示
- 右クリックで復元 / 履歴削除
- 在庫一覧と同様に、列幅をタッチしやすく変更可能

## 置けないマス設定

- 真上ビューのマスを使用禁止にできます
- 既にパレットがあるマスは設定不可
- 真上ビューと45度ビューの両方に表示

## パレット番号重複

パレット番号が重複した場合は、自動で連番を付けます。

例:

- `R080324`
- `R080324-1`
- `R080324-2`

対象:

- 新規登録
- パレット編集
- 出庫履歴からの復元
- 積み替えで作る空パレット

## 保存

通常保存先:

- `inventory-data.json`

保存タイミング:

- 編集確定時
- ダイアログ OK 時
- 移動完了時
- 積み替え確定時
- 出庫確定時
- 新規登録確定時

保存方式:

1. `inventory-data.json.tmp` に書き込み
2. 書き込んだ tmp を JSON として再読込検証
3. 既存本体があれば `.bak` をコピーで作成
4. 検証済み tmp を本体へ置換
5. tmp ゴミは削除

読み込み順:

1. 本体
2. `.bak`
3. 両方壊れていたら復旧ダイアログを出して停止

ログ:

- 保存 / 読込失敗は `store-error.log`
- 壊れた本体は `*.corrupt.json` として退避

## 主なファイル

- `warehouse_app.py`
  - アプリ本体
- `requirements.txt`
  - Python依存関係
- `run_pyside.bat`
  - Python 実行用
- `warehouse_app.spec`
  - PyInstaller 用設定
- `icon.ico`
  - アプリ用アイコン
- `inventory-data.json`
  - 通常保存データ

## 実行方法

### Python で起動

1. Python 3.11 以降を用意
2. `pip install -r requirements.txt`
3. `run_pyside.bat` を実行

### EXE 化

- `warehouse_app.spec` または `WarehouseApp.spec` を利用
- アイコンは `icon.ico` を使用
